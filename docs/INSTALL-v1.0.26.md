## 用户验收

1. 两平台手机/扫码等登录方式和登录方式选择页：确认底部插画已移除，二维码、输入、键盘避让、提交和返回正常。
2. 网易云好友聊天：重新进入截图中的会话，核对本次结束记录和旧记录是否显示卡片；打开本次实际数据与官方详情，切换账号不能保留旧详情。本轮通过了模拟请求身份和合成消息解析测试，尚未读取该条真实私信，不能替代此步骤。
3. 网易云和酷狗分别打开首页、分类、歌单、歌曲列表、专辑、歌手、个人音乐库、搜索和音效目录，等待成功加载及封面显示。清掉后台后重新打开相同账号与页面：应先恢复已有内容，后台成功后更新；无网络时保留已缓存内容。第一次加载、未保存或已淘汰的资源仍可能显示正常加载状态。
4. 歌曲播放页和列表：退出后再次打开同一封面，检查已缓存图片复用；不同图片 ID、版本和尺寸不能串图。系统清除应用数据、重新安装或文件损坏不会保留缓存。登录凭据、播放/下载地址、写操作与一起听实时状态继续实时读取。
5. 已加载多页列表时等待后台刷新，检查后续页、当前滚动及输入保持；收藏、编辑或删除歌单后应以平台确认的新内容为准。切换同平台不同账号、切平台、退出登录后不得出现前账号私有列表。
6. 依次从发现向我的切换：新页从左进入、旧页向右离开；反向相反。快速连点应到达最后选择，详情返回、玻璃材质和减少动态效果保持。
7. 一起听退出后本机继续播放、原有下载/签到/诊断及原生长期稳定性继续由用户自行复测；若异常退出，保留应用可导出的脱敏诊断。主机结果不代表持续 120 FPS 或永久修复。

应用正常清后台不会主动清除本版缓存；缓存采用私有目录、按需保存与容量淘汰。数据上限 32 MiB / 800 条，图片上限 256 MiB / 4000 张，详见修改说明。磁盘读取和图像解码仍需要少量时间，不能承诺任意设备均零帧显示。

## 另一台电脑重建

完整源码 ZIP 内 `SOURCE-SNAPSHOT.json` 是本版清单，逐文件记录摘要。原工作区的 1.0.24 历史清单保持，归档内另存为 `SOURCE-SNAPSHOT-v1.0.24-BASELINE.json`。ZIP 自身摘要在外置核验与 SHA256 中，避免自引用。

本机 Flutter 3.41.9 / Dart 3.11.5 位于 `D:/CodexCache/flutter-3.41.9`；Temurin JDK 17.0.20.1+1、Android SDK、Build Tools 35.0.0 与 NDK 28.2.13676358 使用 `D:/CodexCache/android-build/`。新电脑需自行配置本机 SDK 路径，不复制 local.properties、口令或签名材料进源码。

构建命令：`tool/build_android_release_apk.ps1 -VersionName 1.0.26 -VersionCode 47 -FlutterSdkRoot <Flutter3.41.9根目录>`。保留 pub 阶段更新插件注册，依赖锁必须匹配；构建器验证内置版本说明、固定双 ARM 定制引擎和正式素材排除。共享 pubspec 的 Stable 历史版本不等于此 APK 的公开版本。

构建后由用户私有保留的原签名材料及 `tool/sign_android_release_apk.ps1` 签名，口令通过环境变量提供。源码包含第三方源码、许可及固定引擎，不含 keystore、应用私钥、口令、缓存、APK 或私有诊断证据。保留旧 1.0.25 冻结物；本次未 Git 提交推送或发布 music/GitHub。
