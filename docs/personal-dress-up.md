# 个人装扮

入口：设置 → 装扮 → 我的风格。全部免费、本地保存，无订阅判断。套装、歌词、挂件分页复用下载管理的 `BetaSwipePages`，支持点击和左右滑动，各自保留滚动位置。

## 默认与搭配

- 原有主题、进度轨道与角色选择保持独立。新偏好保存在 `music_personal_style_v1`；未知字段或损坏数据逐项回退。
- 首次使用保持原有封面、头像、歌词和迷你播放器外观。播放器氛围默认关闭。
- 六套配色会一次性推荐对应歌词高亮与头像挂件，之后各项可单独调整。选择配色“默认”只恢复主题配色；顶部“恢复默认”重置所有本页选择。
- 头像挂件只装饰当前用户自己的头像，不改变歌手、评论作者或会员身份标识。

## 功能范围

- 相框：默认、拍立得白边、邮票边框，用于全屏播放器主封面。
- 歌词：清晰／柔和／醒目预设，字号、行距、设备系统衬线字体和高亮色；测量缓存随样式变化失效，以保持逐行跟随位置。
- 分享海报：默认、演出票根、杂志封面、手写便签、复古磁带标签。沿用原有歌曲链接校验与相册保存流程，导出 1080×1704 PNG。
- 听歌纪念卡：在已有记录的听歌回顾页主动生成。按选定月份或全年真实本地记录生成，支持默认、月度明信片和年度收藏卡外观，可保存 PNG；不补造数据。
- 迷你播放器：默认、磨砂玻璃、细边金属、柔和彩色描边，保留原有手势和控制按钮。
- 播放器氛围：柔和光晕、星空、唱片光圈，可调强度；光晕使用低分辨率封面模糊颜色。属于播放状态驱动的缓慢动画，不读取 FFT 或实时节拍。暂停缓停、后台或隐藏立即停止，系统减少动态效果时静止，强度为零时不运行动画。
- 发现页音符微光：在现有冷启动招呼语之后出现约两秒，再淡出；本次冷启动仅一次，可关闭。减少动态效果或进入后台时跳过。

未增加播放按钮皮肤、胶片齿孔相框、透明亚克力相框或角色互动。

## 验证

新增测试覆盖偏好恢复、快速保存顺序、默认复原、损坏数据、套装与自定义独立、分页滑动与 2 倍字号、头像作用域、氛围暂停／后台／零强度停止、真实纪念卡导出、五种海报 PNG，以及发现页装饰只播放一次和减少动态效果。相关原有测试覆盖分享、听歌统计、进度装扮、播放器入口和迷你播放器重建次数。

已同步目标分支 `59036a4` 的最新代码，保留歌词滚动选句、逐曲时间校准、收藏总数和滑动进入评论。另加自定义字号／行距／高亮后的歌词选句播放兼容测试。经典播放器视觉与可读性测试按默认通道运行，Beta 界面回归按 `--flavor beta` 运行，避免用错误通道的界面键值判断失败。发布前仍需 Android 真机检查动画观感、系统字体及相册权限。
