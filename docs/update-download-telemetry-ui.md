# 应用内更新：下载前与传输进度

适用于现有 Beta/原生界面的更新抽屉。基于 beta 的 8440e04，已包含源切换修复 PR #19；不改播放器、音源、版本清单或正式/实验渠道隔离。

## 可见变化

- 下载前保留当前版本、新版本、包大小和完整 releaseNotes；提高面板背景遮挡，避免首页封面透过后影响阅读。
- 图标、应用名称、更新状态组成紧凑页头，版本采用“当前 → 新版”；更新说明单独滚动。正常屏幕的操作区固定，短屏和大字体改为整体滚动。
- 传输卡片显示文件落盘进度、实时速度、预计剩余时间、接收节点数；“传输详情”可展开 HTTPS、普通节点、种子节点速率。
- 只有可用统计、正在接收的节点和已校验 P2P 字节同时存在时才显示“P2P 协同下载”。连接中、仅连接无数据、统计不可用分别展示，不虚构加速倍率。
- 暂停、取消收尾、校验、待安装分别展示；终态清除旧速度和 ETA。系统确认安装、强制更新限制、稍后提醒、完整更新说明入口沿用原控制器。
- 重新打开抽屉订阅现有任务快照，不另起下载。观察层不发额外请求；旧 HTTPS transport 无此能力仍可使用。
